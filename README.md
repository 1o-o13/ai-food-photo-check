# 메뉴 사진 vs 실제 음식 비교

음식점 사장님이 **메뉴에 올린 사진**과 **실제로 나가는 음식 사진**을 함께 올리면, 손님이 "사진이랑 다르다"고 느낄 차이를 AI가 찾아주는 사이트예요.

- **AI 비교 (3단계)**: 두 사진을 Claude API로 비교해서 일치도 점수, 항목별 차이(양, 구성, 크기, 그릇, 색, 질감), 고치는 법을 알려줘요.
- **직접 검토 신청 (2단계)**: 여러 메뉴나 메뉴판 전체는 신청 폼으로 받아서 사람이 직접 봐요.

## 파일 구조

```
index.html        화면 전체 (사진 두 장 업로드 + 비교 결과 + 설명 글)
api/analyze.js    서버리스 함수: 사진 두 장을 받아 Claude API로 비교하고 결과를 돌려줌
api/prompt.js     AI에게 주는 비교 기준, 점수 기준, 출력 형식
.env.example      필요한 환경변수 목록
```

## 처리 흐름

1. 브라우저에서 두 사진을 각각 긴 변 1024px로 줄여요. 토큰 비용과 전송 시간을 아끼려고요.
2. `/api/analyze`로 두 사진을 함께 보내요.
3. 서버는 IP별 하루 횟수를 확인한 뒤, "사진 A: 메뉴 사진", "사진 B: 실제 음식"이라는 이름표를 붙여 Claude API에 보내요. 실제 음식(B)을 기준으로 메뉴 사진(A)이 얼마나 다른지 비교해요.
4. AI 답변에서 JSON만 꺼내 형식을 바로잡고 브라우저로 돌려줘요.
5. 사진은 어디에도 저장하지 않아요.

## 배포 방법

### 1. Anthropic API 키 만들기
1. [console.anthropic.com](https://console.anthropic.com)에 가입하고 결제 수단을 등록해요.
2. API Keys에서 새 키를 만들어요.
3. **꼭 할 것**: Limits(사용 한도) 메뉴에서 **월 사용 한도**를 낮게 걸어두세요. 처음에는 5~10달러 정도면 충분해요. 요금 폭주를 막는 가장 확실한 방법이에요.

### 2. GitHub에 올리기
1. GitHub에서 새 저장소를 만들어요.
2. 이 폴더의 파일을 전부 올려요. `.env.local` 같은 키가 든 파일은 올리지 마세요.

### 3. Vercel로 배포하기
1. [vercel.com](https://vercel.com)에 GitHub 계정으로 가입해요.
2. Add New → Project에서 방금 만든 저장소를 가져와요. 설정은 기본값 그대로 Deploy를 눌러요.
3. Settings → Environment Variables에 `ANTHROPIC_API_KEY`를 넣어요. 나머지는 `.env.example`을 보고 필요한 것만 넣으면 돼요.
4. Deployments에서 Redeploy를 눌러 환경변수를 적용해요.

### 4. (추천) 서버 쪽 횟수 제한 켜기
브라우저 쪽 제한은 시크릿 창만 열어도 풀려요. 서버에서도 막으려면:
1. [upstash.com](https://upstash.com)에서 무료 Redis 데이터베이스를 만들어요.
2. REST URL과 Token을 Vercel 환경변수 `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN`에 넣어요.
3. 내 도메인을 `ALLOWED_ORIGIN`에 넣으면 다른 사이트가 내 API를 가져다 쓰는 것도 막을 수 있어요.

### 로컬에서 테스트하기
```bash
npm i -g vercel
cp .env.example .env.local   # 키를 채워 넣기
vercel dev                    # http://localhost:3000
```

## 2단계: 직접 검토 신청 폼 만들기

**Tally**(tally.so)를 추천해요. 무료이고, 신청자가 로그인하지 않아도 사진을 올릴 수 있어요. 구글 폼은 파일을 올리려면 신청자가 구글에 로그인해야 해서 신청이 줄어들 수 있어요.

폼 질문 예시:
1. 가게 이름 (선택)
2. 업종: 한식 / 중식 / 일식 / 양식 / 카페·디저트 / 기타
3. 사진을 어디에 쓰시나요? 배달앱 / 매장 메뉴판 / SNS / 기타
4. 메뉴에 올린 사진 (최대 5장)
5. 같은 메뉴의 실제 음식 사진 (최대 5장, 4번과 같은 순서로)
6. 메뉴 사진은 어떻게 만드셨나요? 직접 촬영 / 촬영 후 AI 보정 / AI로 생성 / 업체 촬영 / 모르겠음
7. 가장 고민되는 점 (자유 입력)
8. 결과를 받을 이메일
9. 개인정보 수집·이용 동의 (필수 체크)

폼을 만든 뒤 `index.html`에서 `const FORM_URL = "";` 따옴표 안에 폼 주소를 넣으면 신청 버튼이 연결돼요.

**운영 팁**: 처음 20~30건은 직접 보고 답장하세요. 받은 질문과 내가 쓴 피드백을 모아두었다가 `api/prompt.js`의 진단 기준에 반영하면 AI 진단 품질이 올라가요.

## 비용 관리

- Vercel Logs에 매번 `usage`(입력·출력 토큰 수)가 찍혀요. 일주일 정도 모아서 평균을 내고, Anthropic 공식 가격표로 **비교 1회당 비용**(사진 두 장)을 계산해두세요. 이력서에 쓸 좋은 숫자가 돼요.
- 비용을 더 줄이는 방법: 사진을 더 작게 줄이기(예: 768px), `max_tokens` 낮추기, 같은 사진은 다시 보내지 않게 막기.
- 모델을 바꾸려면 `ANTHROPIC_MODEL` 환경변수만 바꾸면 돼요.
